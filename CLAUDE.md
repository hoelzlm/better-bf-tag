# better-bf-tag

Alarm- und Planungssoftware für den BF-Tag der Jugendfeuerwehr (Flutter + eigenes Backend).
Dokumentation: `docs/README.md`.

## Agent skills

### Issue tracker

Issues und Specs liegen als Markdown-Dateien unter `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Die fünf Standard-Rollen (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix), unverändert übernommen. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: ein `CONTEXT.md` im Root plus `docs/adr/`. See `docs/agents/domain.md`.
