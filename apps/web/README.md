# apps/web

Flutter-Web-App mit zwei Bereichen (noch nicht angelegt):

- `/admin`: Verwaltung und Leitstelle
- `/monitor`: Alarmmonitor im Kiosk-Modus

Siehe [docs/06-clients.md](../../docs/06-clients.md) und [ADR 0004](../../docs/adr/0004-flutter-web.md).

Anlegen später mit:

```sh
flutter create --org de.<domain> --project-name bftag_web --platforms web apps/web
```
